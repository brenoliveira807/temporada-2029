# Master Liga - Projeto de Ligas de Futebol

Este é um projeto que exibe as tabelas e resultados de jogos de competições de futebol brasileiro.

## Estrutura do Projeto

```
master-liga/
├── index.html                      # Página inicial (Brasileirão Série A)
├── copado-brasil.html              # Copa do Brasil 2029
├── copa-libertadores-2029.html     # Copa Libertadores da América 2029
├── brasileirao-serie-a/            # Imagens dos escudos (Brasileirão Série A)
├── brasileirao-serie-b/            # Imagens dos escudos (Brasileirão Série B)
├── libertadores/                   # Imagens dos escudos (Copa Libertadores)
└── copado-brasil/                  # Imagens dos escudos (Copa do Brasil)
```

## Navegação

### Página Inicial (`index.html`)
- Exibe a tabela do Brasileirão Série A Temporada 2029
- Menu de navegação para acessar as outras competições

### Copa do Brasil (`copado-brasil.html`)
- Exibe os resultados da segunda e terceira fase
- Menu de navegação entre todas as competições

### Copa Libertadores (`copa-libertadores-2029.html`)
- Exibe resultados da fase de grupos e oitavas de final
- Menu de navegação entre todas as competições

## Funcionalidades

- 🏆 Escudos das equipes com imagens em alta resolução
- 📊 Tabelas com resultados dos jogos
- 🎨 Design responsivo e moderno com tema escuro
- 🔗 Navegação intuitiva entre as competições

## Rodar o Projeto

Para visualizar o projeto no GitHub Pages ou localmente:

1. Clone o repositório
2. Abra qualquer um dos arquivos HTML em seu navegador
3. Ou configure o GitHub Pages nas configurações do repositório

## Tecnologias

- HTML5
- CSS3 (com animações e gradientes)
- Google Fonts (Titillium Web)
- Imagens SVG e WebP para os escudos

## Equipe

Desenvolvido para acompanhar os resultados dos jogos do Corinthians Paulista na temporada 2029.
